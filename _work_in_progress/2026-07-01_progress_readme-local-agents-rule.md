# 進捗レポート: README.LOCAL.md ローカル作業メモ運用ルール追加 (2026-07-01)

## 目的

複数のローカル環境（本体ローカル / サブローカル ×2）での並行作業が増えてきたため、各ローカル固有の作業メモを残す置き場として `README.LOCAL.md`（既に `.gitignore` 対象）の使い方を Claude / Copilot 双方の指示書に明文化する。

## 変更点の要約

- `CLAUDE.md` の「サブローカル並行作業運用（予備作業場）」節直後に **「`README.LOCAL.md`（ローカル環境ごとの作業メモ）」** 小節を新設。
- `.github/copilot-instructions.md` の同節直後に同等内容を反映（指示書の両反映ルールに準拠）。
- `CHANGELOG.md` 先頭へ運用ルール追加エントリを追記。

## 決定事項（運用ルール）

- **役割**: `README.LOCAL.md` は `.gitignore` 対象（Git 管轄外）のローカル専用メモファイル。commit / push / pull で他ローカルへ共有されない。
- **用途**: そのローカル固有の情報（物理パス、現在チェックアウト中のブランチ・用途、作業中/一時中断中のタスク、引き継ぎ時の注意点）を、そのローカルの利用者・エージェント自身のための備忘録として記録する。
- **`_work_in_progress/` との使い分け**: 複数ローカル横断で共有すべき正式な進捗・決定事項は引き続き `_work_in_progress/`（Git 管理下）に記録し、`README.LOCAL.md` はそれを補う「そのローカルだけのメモ」として扱う。正式な進捗ログの代替にはしない。
- **生成時の制約**: ファイルが無い場合は最低限のテンプレート（ローカルパス等）を作成してよいが、パス以外の作業メモ内容は User が手動追記する前提とし、Claude/Copilot は創作内容や未確認の推測を書き込まない。
- **配布方式**: 本節は `CLAUDE.md` / `.github/copilot-instructions.md` の両方へ記載することで、全ローカル環境へ commit / pull 経由で共通配布する。
