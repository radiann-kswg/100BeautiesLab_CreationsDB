# 進捗レポート: サブローカル並行作業の運用ルール追加 (2026-06-27)

## 目的

本体ローカル（メイン作業ディレクトリ）が特定ブランチで作業中でも、別ブランチの作業を止めずに進められるよう、サークル主が用意した 2 つのサブローカル（同一リモートを参照する予備クローン）を、Cowork プロジェクト指示として正式に活用できるようにする。

## 変更点の要約

- `CLAUDE.md` の「ブランチ運用方針」直後に **「サブローカル並行作業運用（予備作業場）」** 節を新設。
- `.github/copilot-instructions.md` の「ブランチ運用方針」直後に同等内容を反映（指示書の両反映ルールに準拠）。
- `CHANGELOG.md` 先頭へ運用ルール追加エントリを追記。

## 決定事項（運用ルール）

- **役割**: サブローカル ×2 は固定用途を持たない「ブランチ単位で使い分け可能な汎用の予備作業場」。恒久割り当てはしない。
- **発動条件**: Claude / AI エージェントの自律判断。とくに「本体が特定ブランチで作業中（未コミット変更あり等）に別ブランチを並行」する同時作業不可の状況では、サブローカルでの別ブランチ作業を**必須**とする。
- **配布方式**: 物理パスはハードコードせず、git 管理ファイルへの記載で全ローカル環境へ commit / pull 経由で共通配布する（個別ローカルへの手書き複製はしない）。
- **安全則**: 着手前の `git branch --show-current` / `git status` 確認、同一ファイル多重編集の回避、`push`→`pull`（または merge）による同期明示、横断作業ログの `_work_in_progress/` 記録、既存ブランチ運用方針の遵守。
