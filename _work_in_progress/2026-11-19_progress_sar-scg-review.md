# SAR / SCG の外見・配色入力のレビュー

## 目的と対象

User の依頼で `ponytail:review`（導入名 `ponytail-review`）を使用し、外見・配色入力と表示・継承をレビューしたよ。リファクタリングも依頼されているため、確認できた問題と近傍の重複だけを修正したよ。

- 固定したレビュー範囲: `1f1337bf^..1f1337bf`（14ファイル）。今回の修正差分も再確認したよ。
- 変更の目的: SAR / SCG の画像由来の外見・配色を記録し、SAR の共通制服色と形状enumを利用。SCG-N / USE は NTS から外見を継承するよ。
- 想定する使われ方: 静的JSONを使うキャラクター一覧・詳細表示とローカル/CIのデータ検査。新しい共有状態・通信・サービス処理は含まないよ。
- 確認範囲: 変更ファイル、rendererの呼び出し元・登録・helper契約、実enrich、関連テスト、README・schema資料、既存の採色根拠。

## 指摘（修正済み / Should fix）

### 1. ネゝコの共通色上書き名に旧ラベルが残っていた

- **対象**: SAR Primary の Cat、`#C77FAF` の `#ColorRole_CommonOverride`。
- **問題**: 青の共通色が「アクセント色① / Uniform Accent 1」へ整理された後も、この1行だけ旧名だったよ。上書き先を示す名称が現行メタと一致していなかったよ。
- **最小修正**: JP / EN のラベル2値を現在の共通メタと同じ表記へ同期。HEX・役割・適用部位・形態は保持したよ。作業ログの現在表も白・薄灰色を含めて同期したよ。
- **放置した場合**: 表示上の名前が食い違い、上書き対象の確認・後続更新で取り違えやすくなるよ。色値そのものの誤りや実行時クラッシュは確認されていないよ。
- **再発防止**: SAR の全上書き色について JP / EN の組が現在の共通メタに存在することを検査。修正前はこの1行で失敗し、修正後に成功したよ。

## 近傍の既存不具合とリファクタリング

`tests/patch-colorpalette.test.js` は共有の `colorDistance` をimportしつつ同名関数をローカル定義していたよ。これは今回のコミットより前（`b64f8184`）から存在し、標準Node ESMの構文検査で二重宣言エラーになったよ。Vitestの変換経由では実行できるため、CI全体が停止する問題とは扱っていないよ。

ローカル関数は共有関数と本文が同じで、81組の入力でも結果が一致。重複関数と、その関数だけが使っていた `hexToRgb` importを削除したよ。修正後は標準構文検査も成功したよ。放置すると標準のESMパーサーでは読めない状態が続くため、今回触るテスト内で解消したよ。

共通色の読取テストはNTS / UBL / SARを表形式にまとめ、色の追加やメタの並べ替えに不要に依存しない期待値へ統一したよ。SARへの共通色追加で失われた「宣言の無い作品は空配列」の検証はSCGを使って戻したよ。新しいhelperや依存関係は追加していないよ。

## 設定・継承・描画の確認結果

- 対象17レコードの外見298属性と形状辞書参照13件に、追加の未解決参照はなかったよ。配色チップ・通常制服の採色根拠を照合し、原画差として残した白255/254、黄土色の差、同系統の複数色も確認したよ。
