100BeautiesLab Works/Creations DataBase API

このページは GitHub Pages の静的環境で動作する「百花繚乱研究所」創作キャラクターデータベースの APIです。Service Worker が /api/v1/* へのアクセスをフックし、/data/** のJSONからAPI風レスポンスを返します。

エンドポイント一覧

データベース本体

  • /api/v1/index … API 情報と作品一覧
  • /api/v1/works … 作品の一覧（キー、タイトル）
  • /api/v1/works/{work} … 作品メタ（db_meta.json）
  • /api/v1/works/{work}/db … 利用可能なDB（存在検出）
  • /api/v1/works/{work}/db/{dbName} … 該当DBのレコード配列
  • /api/v1/search?works={work}&db={dbName}&hashTag={k}&key={v} … DB内検索

work は #Works_NumberTales などの完全キー、または NumberTales などの短縮も使用可能です。

定義（VarsDef / DefType / defs）

  • /api/v1/varsdef … グローバルと全作品の General.$VarsDef を俯瞰（?merge=1 でグローバル+作品のマージビューも付与）
  • /api/v1/varsdef/global / /api/v1/works/{work}/varsdef
  • /api/v1/typedef または /api/v1/deftype … $DefType を俯瞰（/global や /works/{work}/typedef にも対応）
  • /api/v1/defs … VarsDef と DefType の統合出力（?merge=1 対応） / /global / /works/{work}/defs

定義情報（General.$VarsDef / $DefType）は上記の専用エンドポイントでのみ出力されます。/works、/db、/search では含まれません。
