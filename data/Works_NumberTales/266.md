## 第一部：ナイトの跳躍角 arctan(1/2)

貴君の言う「約26.6°」、その正体は $\arctan\frac{1}{2} = 26.5650511770779893...^\circ$ である。四捨五入すれば確かに26.6。ここから既に面白い。

- **オイラーの美しい等式**：$\arctan\frac{1}{2} + \arctan\frac{1}{3} = 45^\circ$（厳密に、誤差ゼロ）。すなわち「1:2の跳躍」と「1:3の跳躍」を足すと、ぴったり直角の半分になる。マチン型公式の系譜だ。
- **倍角にすると化ける**：$2 \times 26.565^\circ = 53.1301...^\circ$ ――これは何を隠そう **3:4:5の直角三角形**の角である。偶然ではない。ガウス整数で見れば $(2+i)^2 = 3+4i$。ナイトの移動ベクトルを「複素数として二乗」すると、人類最古のピタゴラス数が出てくるのだ。
- さらに四乗：$(2+i)^4 = -7+24i$ → **7:24:25** の三角形。ナイトは跳ぶたびにピタゴラス数を生成している、と言い換えてもよい。
- **$2+i$ はガウス素数である**（ノルム $2^2+1^2=5$）。ナイトの移動距離 $\sqrt{5}$ が無理数なのも、$5 = 1^2+2^2$ という分解の一意性から来ている。
- そして極めつけ、**ニーヴンの定理**。$\arctan\frac{1}{2}$ は $\pi$ の有理数倍では**ない**。ゆえにこの角度で回転を何度繰り返しても、決して厳密には元の向きに戻らない。盤上の駒がなす角が、周期に絶対に囚われない――これぞ我輩の愛する特異的性質だ。

## 第二部：$2^{\sqrt{2}} = 2.66514414269...$

貴君が掴んだ「上3桁266」、これが本命だ。この数には名がある。**ゲルフォント＝シュナイダー定数**。別名**ヒルベルト数**。

- ヒルベルトの**第7問題**そのものであり、1934年ゲルフォント、1935年シュナイダーが独立に解決した。結論は「**超越数**」――代数方程式の根には決してなり得ぬ数だ。
- そして提督殿、ここを見よ。$(2^{\sqrt{2}})^{\sqrt{2}} = 2^2 = \mathbf{4}$。**無理数の無理数乗が、こうもあっさり4になる。** ……ふふ、我輩の数字だな。
- 平方根を取れば $\sqrt{2^{\sqrt{2}}} = (\sqrt{2})^{\sqrt{2}} \approx 1.63252$。これは「無理数の無理数乗が有理数になりうる」ことを**具体例を特定せずに証明する**、あの有名な非構成的証明の主役だ。
- **なぜ「2.66」なのか**、その理由まで示そう。連分数展開は $[2;1,1,1,\mathbf{72},3,4,...]$ ――第5項に突如**72**という巨大な数が現れる。連分数において大きな項の直前は、極めて良い有理近似を意味する。その近似値が $[2;1,1,1] = \dfrac{8}{3} = 2.6666...$ なのだ。
  つまり **$2^{\sqrt{2}}$ の頭が「266」になるのは、この数が $8/3$ に異様に近いから**（差はわずか0.0015）。貴君の見つけた「266」は、偶然の数字列ではなく**連分数の構造が生んだ必然**だったというわけだ。

## 第三部：整数としての266

- **素因数分解 $266 = 2 \times 7 \times 19$**。相異なる3素数の積、いわゆる**楔数（sphenic number）**。約数はちょうど8個。
- 素因数の和 $2+7+19 = \mathbf{28}$ ――**完全数**である。
- 桁和は $2+6+6=14$、そして $266 \div 14 = 19$。割り切れる。よって266は**ハーシャッド数（ニヴン数）**。しかも商が自身の素因数という律儀さだ。
- **ここは特に聞け、提督殿。$266 = 222_{(11)}$ である。** 11進法でゾロ目になるのだ。同時に $266 \mid 11^3-1$ も成り立つ。……そして $444_{(11)} = 532 = 266 \times 2$。**貴君の持ってきた266は、11進法における「我輩」のちょうど半分**ということになる。……ふ、ふん、別に嬉しくなどないぞ。
- $266 = 2^8 + 10$。
- 三平方和では $266 = 16^2+3^2+1^2$ ほか5通り。だが**二平方和では表せない**（$19 \equiv 3 \pmod 4$ が奇数乗で現れるため）。フェルマーの二平方定理が禁じている。
- **ノントーシェント**である。すなわち $\varphi(n)=266$ を満たす自然数 $n$ は存在しない。証明は容易だ――$p-1 \mid 266$ なる素数は $2,3,29$ のみ、しかし $\varphi(29)=28$ は4を含み $266$ は2を1個しか持たぬ。ゆえに $n=2^a3^b$ しか残らず、その $\varphi$ は $2^x3^y$ 型。$7$ も $19$ も作れぬ。**背理法により、266は誰の「オイラー像」にもなれない孤独な数だ。**
- 連続整数和：$266 = 35+36+\cdots+41$（7項）$= 5+6+\cdots+23$（19項）。
- 約数和 $\sigma(266)=480$、真の約数和は214。ゆえに**不足数**。

## 第四部：科学における266

- **266 nm** ――Nd:YAGレーザー基本波 1064 nm の**第4高調波**。1064 → 532（緑）→ 355 → **266**（深紫外）。**ちょうど4分の1**である。……4分の1。我輩に縁が深すぎる数字だ。
- 酸素原子1個の質量が約 $2.66 \times 10^{-26}$ kg。$16\,\mathrm{u} \times 1.6605\times10^{-27}$ から出る値だ。
- **$^{266}\mathrm{Mt}$（マイトネリウム266）**――1982年、GSIで最初に合成が報告された109番元素の同位体がこの質量数である。
- 土星の自転軸傾斜角が $26.73^\circ$。ナイトの角に近い、が――これは近いだけで理論的必然はない。近似で満足するのは我輩の流儀ではないので、参考程度に留めよ。
- ……なお、266日はヒトの受精からの平均妊娠期間とされておる、が――こ、これは微分方程式で導出できるものではないので、僕の管轄外だ！ **ｺﾞﾎﾝ!!** ……我輩は数理的裏付けのある事象のみを扱う。
