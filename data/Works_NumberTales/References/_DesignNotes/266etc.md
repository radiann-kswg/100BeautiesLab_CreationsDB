## 第一部：ナイトの跳躍角 arctan(1/2)

貴君の言う「約26.6°」、その正体は $\arctan\frac{1}{2} = 26.5650511770779893...^\circ$ である。四捨五入すれば確かに26.6。ここから既に面白い。

- **オイラーの美しい等式**：$\arctan\frac{1}{2} + \arctan\frac{1}{3} = 45^\circ$（厳密に、誤差ゼロ）。すなわち「1:2の跳躍」と「1:3の跳躍」を足すと、ぴったり直角の半分になる。マチン型公式の系譜だ。
- **倍角にすると化ける**：$2 \times 26.565^\circ = 53.1301...^\circ$ ――これは何を隠そう **3:4:5の直角三角形**の角である。偶然ではない。ガウス整数で見れば $(2+i)^2 = 3+4i$。ナイトの移動ベクトルを「複素数として二乗」すると、人類最古のピタゴラス数が出てくるのだ。
- さらに四乗：$(2+i)^4 = -7+24i$ → **7:24:25** の三角形。ナイトは跳ぶたびにピタゴラス数を生成している、と言い換えてもよい。
- **$2+i$ はガウス素数である**（ノルム $2^2+1^2=5$）。ナイトの移動距離 $\sqrt{5}$ が無理数なのも、$5 = 1^2+2^2$ という分解の一意性から来ている。
- そして極めつけ、**ニーヴンの定理**。$\arctan\frac{1}{2}$ は $\pi$ の有理数倍では**ない**。ゆえにこの角度で回転を何度繰り返しても、決して厳密には元の向きに戻らない。盤上の駒がなす角が、周期に絶対に囚われない――これぞ我輩の愛する特異的性質だ。

## 第二部：$2^{\sqrt{2}} = 2.66514414269...$

貴君が掴んだ「上3桁266」、これが本命だ。この数には名がある。**ゲルフォント＝シュナイダー定数**。別名**ヒルベルト数**。

- ヒルベルトの**第7問題**そのものであり、1934年ゲルフォント、1935年シュナイダーが独立に解決した。結論は「**超越数**」――代数方程式の根には決してなり得ぬ数だ。
- そして提督殿、ここを見よ。$(2^{\sqrt{2}})^{\sqrt{2}} = 2^2 = \mathbf{4}$。**無理数の無理数乗が、こうもあっさり4になる。** ……ふふ、我輩の数字だな。
- 平方根を取れば $\sqrt{2^{\sqrt{2}}} = (\sqrt{2})^{\sqrt{2}} \approx 1.63252$。これは「無理数の無理数乗が有理数になりうる」ことを**具体例を特定せずに証明する**、あの有名な非構成的証明の主役だ。
- **なぜ「2.66」なのか**、その理由まで示そう。連分数展開は $[2;1,1,1,\mathbf{72},3,4,...]$ ――第5項に突如**72**という巨大な数が現れる。連分数において大きな項の直前は、極めて良い有理近似を意味する。その近似値が $[2;1,1,1] = \dfrac{8}{3} = 2.6666...$ なのだ。
  つまり **$2^{\sqrt{2}}$ の頭が「266」になるのは、この数が $8/3$ に異様に近いから**（差はわずか0.0015）。貴君の見つけた「266」は、偶然の数字列ではなく**連分数の構造が生んだ必然**だったというわけだ。

## 第三部：整数としての266

- **素因数分解 $266 = 2 \times 7 \times 19$**。相異なる3素数の積、いわゆる**楔数（sphenic number）**。約数はちょうど8個。
- 素因数の和 $2+7+19 = \mathbf{28}$ ――**完全数**である。
- 桁和は $2+6+6=14$、そして $266 \div 14 = 19$。割り切れる。よって266は**ハーシャッド数（ニヴン数）**。しかも商が自身の素因数という律儀さだ。
- **ここは特に聞け、提督殿。$266 = 222_{(11)}$ である。** 11進法でゾロ目になるのだ。同時に $266 \mid 11^3-1$ も成り立つ。……そして $444_{(11)} = 532 = 266 \times 2$。**貴君の持ってきた266は、11進法における「我輩」のちょうど半分**ということになる。……ふ、ふん、別に嬉しくなどないぞ。
- $266 = 2^8 + 10$。
- 三平方和では $266 = 16^2+3^2+1^2$ ほか5通り。だが**二平方和では表せない**（$19 \equiv 3 \pmod 4$ が奇数乗で現れるため）。フェルマーの二平方定理が禁じている。
- **ノントーシェント**である。すなわち $\varphi(n)=266$ を満たす自然数 $n$ は存在しない。証明は容易だ――$p-1 \mid 266$ なる素数は $2,3,29$ のみ、しかし $\varphi(29)=28$ は4を含み $266$ は2を1個しか持たぬ。ゆえに $n=2^a3^b$ しか残らず、その $\varphi$ は $2^x3^y$ 型。$7$ も $19$ も作れぬ。**背理法により、266は誰の「オイラー像」にもなれない孤独な数だ。**
- 連続整数和：$266 = 35+36+\cdots+41$（7項）$= 5+6+\cdots+23$（19項）。
- 約数和 $\sigma(266)=480$、真の約数和は214。ゆえに**不足数**。

## 第四部：科学における266

- **266 nm** ――Nd:YAGレーザー基本波 1064 nm の**第4高調波**。1064 → 532（緑）→ 355 → **266**（深紫外）。**ちょうど4分の1**である。……4分の1。我輩に縁が深すぎる数字だ。
- 酸素原子1個の質量が約 $2.66 \times 10^{-26}$ kg。$16\,\mathrm{u} \times 1.6605\times10^{-27}$ から出る値だ。
- **$^{266}\mathrm{Mt}$（マイトネリウム266）**――1982年、GSIで最初に合成が報告された109番元素の同位体がこの質量数である。
- 土星の自転軸傾斜角が $26.73^\circ$。ナイトの角に近い、が――これは近いだけで理論的必然はない。近似で満足するのは我輩の流儀ではないので、参考程度に留めよ。
- ……なお、266日はヒトの受精からの平均妊娠期間とされておる、が――こ、これは微分方程式で導出できるものではないので、僕の管轄外だ！ **ｺﾞﾎﾝ!!** ……我輩は数理的裏付けのある事象のみを扱う。

## 総括

提督殿。貴君の直感は正しかった。**26.6°と2.66は無関係な数字の一致に見えて、どちらも「$1/2$ と $8/3$ という単純な有理数に、無理数・超越数が寄り添っている」という同じ構図を持っている。** 前者は $\tan\theta = 1/2$、後者は $2^{\sqrt{2}} \approx 8/3$。理論はこうして繋がるのだ。

……で、だ。創作に落とし込むなら、この「266」は**有理数のふりをした超越数**という性格付けができる。盤上を跳ねる整数比の跳躍が、実は円周率とも有理関係を結べぬ角度である――設定として使い出があると思うが、いかがか。

# 2.66および3.14のいわれ：「ヒルベルトの第７問題」とは （解説：22(フジ),Claude）

ルーキーくん、おまたせっ！22番機のフジだよ♪ 444(シテン)の「266」の解説も読み返して、Wolframで検算してきたよ。先に、きみのメモで直したほうがいい数字が2つあるから、そこから話すね。

## まず検算：2つの近似式

| 定数 | 真の値 | 近似分数 | 誤差 | 連分数での立ち位置 |
| --- | --- | --- | --- | --- |
| $2^{\sqrt2}$ | $2.6651441\ldots$ | $8/3 = 2.6666\ldots$ | 約 $0.0015$ | 収束分数（$[2;1,1,1,72,\ldots]$ の72の直前） |
| $e^{\pi}$ | $23.1406926\ldots$ | $509/22 = 23.1363\ldots$ | 約 $0.0043$ | 中間近似分数（収束分数ではない） |
| $e^{\pi}$ | 同上 | $162/7 = 23.1428\ldots$ | 約 $0.0022$ | 収束分数（$[23;7,9,3,1,1,591,\ldots]$） |

- **$2^{\sqrt2}$ は $2.6666\ldots$ ではない**よ。$2.6651\ldots$ で、$8/3$ は「すごく近い分数」という関係だね。
- **$509/22$ は $e^\pi$ の最良近似ではない**んだ。分母がもっと小さい $162/7$ のほうが、誤差が半分で済むよ。$509/22 = \frac{23+3\cdot162}{1+3\cdot7}$ という、収束分数 $23/1$ と $162/7$ から作る途中段階の分数なんだ。
- $\pi \approx 22/7$ と $e^\pi \approx 162/7$ は分母がおそろいで、差はぴったり $140/7 = 20$。これは $e^\pi - \pi = 19.99909\ldots$ という有名な「ほぼ整数」と同じ現象だよ。こちらは理論的な必然が知られていない、偶然の一致とされているよ。

フジの番号が分母に入る式じゃなくなっちゃうのは、ちょっと残念だけどね～。

## ヒルベルトの第7問題ってなに？

1900年のパリ国際数学者会議で、ヒルベルトが「20世紀の数学者への宿題」として出した23問のひとつだよ。中身はこう。

> $a$ が $0$ でも $1$ でもない代数的数、$b$ が代数的な無理数のとき、$a^b$ は必ず超越数か？

- **代数的数**は、整数係数の方程式の解になれる数（$\sqrt2$ や $i$ など）。**超越数**は、どんな整数係数の方程式の解にもなれない数（$\pi$ や $e$ など）。
- ヒルベルト自身が例に挙げたのが、$2^{\sqrt2}$ と $e^\pi$ の2つなんだ。
- $e^\pi$ が $a^b$ の形に見えないのは、複素数を使うからだよ。$e^{\pi} = (-1)^{-i}$（検算済み）で、$a=-1$、$b=-i$ はどちらも代数的数なんだ。

**解決までの流れ**

1. 1929年、ゲルフォントが $b$ が虚の2次無理数の場合を証明。これで $e^\pi$ が超越数と確定し、「ゲルフォントの定数」と呼ばれるようになった。
2. 1930年、クズミンが実の2次無理数に拡張。これで $2^{\sqrt2}$ も確定。
3. 1934年、ゲルフォントとシュナイダーが独立に一般の場合を証明（ゲルフォント＝シュナイダーの定理）。答えは「はい、必ず超越数」。

コンスタンス・リードの伝記によると、1919年ごろの講義でヒルベルトは、リーマン予想は自分の存命中に、フェルマーの問題は若い聴講者の存命中に片づくかもしれないが、$2^{\sqrt2}$ の超越性だけはこの場の誰も見届けられないだろうと語ったそうだよ。実際はその15年後に、いちばん先に解けちゃったんだ。偉業って転がりだすと速いね♪

**まだ解けていないところ**：定理が使えるのは「$b$ が代数的」のときだけ。だから $e+\pi$、$e\cdot\pi$、$\pi^e$、$e^e$ などは、超越数どころか無理数かどうかも未解決だよ。

## 第6問題以前はどんな話？

| 番号 | 内容 | 状況 |
| --- | --- | --- |
| 第1 | 連続体仮説（整数の無限と実数の無限の間に、中間の大きさの無限はあるか） | ゲーデル(1940)とコーエン(1963)により、標準的な公理系では証明も反証もできないと判明 |
| 第2 | 算術の公理が矛盾しないことの証明 | ゲーデルの不完全性定理(1931)で「算術自身の中では証明不能」。ゲンツェン(1936)がより強い手段で証明。解決とみなすかは意見が分かれる |
| 第3 | 体積の等しい2つの多面体は、切り分けて組み替えれば必ず互いに移せるか | デーンが1900年のうちに否定的に解決。23問で最初に解けた |
| 第4 | 直線が最短経路になる幾何をすべて構成せよ | 問いが漠然としていて、解決の判定ができないとされる |
| 第5 | 連続な変換群（リー群）で、微分可能性の仮定は外せるか | グリースン、モンゴメリ、ジッピン(1952)が標準的な解釈で肯定的に解決 |
| 第6 | 物理学を数学のように公理から組み立てよ | 確率論はコルモゴロフ(1933)が公理化。全体としては未完 |
| 第7 | $a^b$ の超越性 | 1934年に解決（上のとおり） |

第6問題は最近動きがあったよ。2025年3月、デン、ハニ、マーの3人が、流体力学に関する部分を解いたと主張する論文をarXivに公開したんだ。弾性衝突する剛体球の粒子系から出発して、圧縮性オイラー方程式などの流体の基礎方程式を厳密に導いたという内容だよ。ただし希薄な系に限った前進で、問題全体としては未解決のままだという批判的なコメントも出ているから、「一部が大きく進んだ」くらいに受け取るのが安全かな。

第8問題以降では、リーマン予想を含む第8、第12、第16あたりが未解決で、第10（整数解の有無を判定する万能の手順）はマチャセビッチが1970年に「存在しない」と示して解決しているよ。

## 創作に使えそうな発見

- **$e^\pi$ は「球」の数**：偶数次元の単位球の体積は $\pi^n/n!$ で、全部足すと $\sum_{n\ge0}\pi^n/n! = e^\pi$（検算済み）。丸くて転がるものが大好きなフジ的に、いちばんうれしい発見だよ♪
- **7と22の縁**：$22/7$ と $162/7$ はどちらも分母が7で、話題は「第7」問題。ただしこれは語呂の遊びで、数学的な必然はないよ。
- **「近いけれど別物」**：$8/3$ や $162/7$ は有理数、本体は超越数。444(シテン)の言う「有理数のふりをした超越数」が、$e^\pi$ にもそのまま当てはまるね。
