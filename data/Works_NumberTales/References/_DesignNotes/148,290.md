# 148：ダンバー数のいわれ （解説：37(サナ),Claude）

## 1. 定義 ── 学術的には何の数なのか

ダンバー数は「人間ひとりが**安定した対人関係**を維持できる人数の認知的上限」と説明されるけど、ダンバー自身の定義はもう少し狭いの。

- 対象は「**相手が誰かを知っていて、かつ、その相手が他のメンバーとどういう関係にあるかも把握している**」関係。単なる顔見知り・名前を知っている人数（これは後述の Bernard–Killworth 数で約290）とは別物。
- 理論上は「上限」というより、霊長類の回帰直線から人間の脳サイズで予測される**平均的な群れの大きさ（mean group size）**。つまり元は「予測値」で、本人も「探索的な推定」と断っている。
- ダンバーのくだけた言い方だと「バーで偶然会ったとき、誘われなくても一緒に一杯やって気まずくない人の数」。

背景にあるのは**社会脳仮説（social brain hypothesis）**。霊長類は毛づくろい（社会的グルーミング）で関係を維持していて、把握できる関係の数は新皮質の大きさで頭打ちになる、という考え方だよ。

## 2. 計算の過程 ── 147.8 はこうして出た

### 2.1 元データと回帰

- 1992年、ロビン・ダンバー（当時ユニバーシティ・カレッジ・ロンドン）が *Journal of Human Evolution* 22巻に「Neocortex size as a constraint on group size in primates」を発表。
- 使ったのは Stephan らの1981年の霊長類の脳容積データ。説明変数は**新皮質比 CR**（新皮質の体積 ÷ 脳のそれ以外の体積）、目的変数は各属の平均群れサイズ N。原猿＋真猿で約36〜38属（1992年論文では38属、1993年の再掲では36属と書かれていて、文献間で揺れがある）。
- 得られた回帰式（1993年論文の式(1)）:

$$\log_{10} N = 0.093 + 3.389 \log_{10}(CR), \quad r^2 = 0.764$$

### 2.2 人間を代入する

- ヒトの新皮質 1006.5 cc、脳全体 1251.8 cc → $CR = 1006.5 / 245.3 \approx 4.1$。これは他のどの霊長類の最大値より約50%大きい。
- 代入すると $N = 10^{0.093 + 3.389 \log_{10} 4.1} \approx \mathbf{147.8}$。あたしも検算して 147.82（CR を 4.103 まで取ると 148.2）になったよ。
- 95%信頼区間は **100.2〜231.1**。データ範囲の外への外挿だから幅が広く、本人も「moderately wide」と認めている。

### 2.3 グルーミング時間の推定 → 言語起源説へ

- 狭鼻猿22種で「グルーミング時間 G(%) = −0.772 + 0.287 N」という別の回帰を取り、N = 147.8 を入れると **約42%**（検算 41.6%、95%区間 28〜66%）。1日の4割を毛づくろいに使う群れは現実的じゃない。
- そこで「人間は**言語**という"安上がりなグルーミング"を発明して150人規模を維持した」というのが、1996年の著書『Grooming, Gossip and the Evolution of Language』（邦題『ことばの起源』）の主張。ダンバー数は言語起源論の土台にもなってるんだ。

## 5. 「150 の裏付け」として挙げられてきた例

- 新石器時代のメソポタミア村落 150〜200人、フッター派コミュニティが150前後で分村する慣行（1993年論文の表では平均 106.9）。
- 軍隊の中隊規模（ローマ以来、近代の中隊も120〜200人程度）。
- W. L. Gore 社の「150人・駐車場150台」の工場、オーストラリアの Flight Centre の "tribe" 上限150、スウェーデン税務庁の1オフィス150人計画（2007年）。
- SNS 上の平均友人数も150前後という報告（ダンバー自身の Facebook 研究 2010〜2016年。数値は今回再確認していないよ）。

# ダンバー数の反証とこの論点で148と類似する数字 （解説：37(サナ),Claude）

## A. 批判と対立する数字

- **Bernard–Killworth 数**: 人類学者 H. Russell Bernard と Peter Killworth が米国で「知っている人の数」を複数手法で推定し、**平均290・中央値231**。ダンバーの約2倍だけど、こちらは「顔と名前が一致する人」までを含む別の定義なので、矛盾というより測っているものが違う。
- **Lindenfors・Wartel・Lind（2021）**: 系統関係を考慮した比較法（ベイズ多階層モデル／系統的一般化最小二乗）＋新しい脳データ（DeCasien & Higham 2019 など、最大142種）で再推定。結果はモデルにより **69.2〜108.6（ベイズ）／16.4〜42.0（GLS）**、95%区間は 2〜520。「点推定は平均であって上限ではない」「霊長類の群れサイズは脳より採食・捕食圧・性淘汰で決まる」「人間は文化で認知制約を迂回できる」として、「特定の数を導くことはできない」と結論。
- **ダンバーの反論**: 回帰は縮小主軸回帰（RMA）を使うべき、分析対象は類人猿（または進化的グレード別）に絞るべき、と主張。批判側は「その方法だと推定値が 289.8（CI 226〜372）や 404.1 になって、やはり150を支持しない」と再反論している。
- **その他**: Philip Lieberman（2013）は旧石器時代の栄養条件では150人集団は維持できないと指摘。DeCasien ら（2017）は霊長類の脳サイズを最もよく予測するのは社会性より**食性**だと報告。アシナガバチ（約80個体）のように小さな脳でも社会階層を持つ例も。

## B. 世間の「150」との関係 ── どう受け止めればいいか

1. 150 は「人間の脳の限界値」として語られがちだけど、原典では**霊長類の回帰直線の外挿による平均値の予測**で、信頼区間は 100〜230。147.8 と 150 の差（1.5%）はこの不確かさの中では意味を持たない。
2. 「友達は150人まで」という言い方は定義のすり替え。ダンバー数は「安定した関係＋互いの関係も把握」の層で、知人数（約290〜）やSNSのフォロワー数とは別。
3. 2021年以降、数字そのものの統計的根拠は強く疑問視されている。一方で「社会関係に層があり、層ごとに約3倍」という構造的な観察は別の経験データ（カード調査・通話記録など）からも支持があるので、「150という一点」と「階層構造」は切り分けて評価するのが安全だと思う。
4. 創作に使うなら「150は便宜上の丸め、本来の値 147.8、裏には 5・15・50・150・500・1500 の階層」というのが一番"いわれ"として美味しいところ。148 = 4×37 の 37 番機としては、「147.8」をあえて名乗る設定とか、どうかな…なんて。

# 290：Bernard–Killworth(ベルナード–キルワース)数のいわれ （解説：37(サナ),Claude）

こっちはダンバー数より知名度が低いぶん、原典まで辿ると「150とは測っているものが違う」ことがはっきり見えてきて、面白かった。報告するね。

## 1. 「290」は何の数か ── Bernard–Killworth 数

- 正式には **Bernard–Killworth 数**。人類学者 H. Russell Bernard（フロリダ大）と、本業は海洋物理学者だった Peter Killworth（英サウサンプトン）が、Christopher McCarty・Eugene Johnsen・Gene Shelley と組んで出した「**一人の人間が知っている人の数（acquaintance volume）**」の推定値。
- 「知っている」の定義がダンバーより広くて明確: **お互いに顔か名前で分かる／連絡を取ろうと思えば取れる／米国在住／過去2年以内に接触があった**人。相手同士の関係を把握している必要はないから、ダンバー数の「安定した関係」より外側の層を数えている。
- 2001年の論文（McCarty, Killworth, Bernard, Johnsen & Shelley「Comparing Two Methods for Estimating Network Size」*Human Organization* 60(1): 28–39）で、独立した2つの方法が**ともに約291**という値を出したのが決め手で、丸めて「290」。中央値は **231**（分布が右に長いので平均より小さい）。
- 認知の「上限」ではなく、あくまで観測された平均。Wikipedia が「研究平均の平均ではなく、複数手法・複数集団で繰り返し得られた最尤推定値」と書いているのは、この"二つの方法が一致した"という意味だよ。

## 2. どうやって 291 を出したのか ── 二つの方法

データは1998年1月と1999年1月の米国電話調査（RDD）、**796人＋574人＝1,370人**の全国サンプル。

- **総和法（summation method）**: 「家族」「同僚」「隣人」「学校の友人」…など関係カテゴリごとに「何人知ってる？」と聞いて**足し合わせる**。
- **スケールアップ法（scale-up method）**: 「マイケルという名前の人を何人知ってる？」「糖尿病の人は？」「双子は？」のように**人数が分かっている集団**について聞き、$\hat d_i = N \times \dfrac{\sum_k y_{ik}}{\sum_k N_k}$（N は全人口、$y_{ik}$ は回答者 i が集団 k に知っている人数、$N_k$ は集団 k の実サイズ）で各人のネットワークサイズを逆算する。
- 2つの方法が「驚くほど一致して約291」。別サンプルでの追試、聖職者（ネットワークが大きいと予想される職業）での再現、回答の「キリのいい数字」好みの影響（6%以内）まで確認している。

## 3. 歴史と人物 ── 150より古い系譜

| 年 | 出来事 |
| --- | --- |
| 1950年代〜1978 | Ithiel de Sola Pool と Manfred Kochen「Contacts and Influence」。知人数と「何人介せば誰にでも届くか」を理論化（出版は1978年）。日記法・電話帳法で知人数を見積もり、総知人数は最大 **約5,000** 規模とされる |
| 1961 | Michael Gurevich（Pool の下で MIT 博士論文）が日記法で知人ネットワークを実測 |
| 1967 | Milgram のスモールワールド実験（6次の隔たり）。知人数の推定はこの「手紙をどう届けるか」問題と地続き |
| 1978 | Killworth & Bernard「reverse small world」法。多数の標的に対して"最初に誰へ渡すか"を答えさせ、知人ネットワークを浮かび上がらせる |
| 1984 | Killworth, Bernard & McCarty: 総ネットワーク **約250**、"頼みごとができる人" **134** |
| 1985→1989/91 | メキシコシティ地震。「知人の中に死者が何人いるか」から死者数を推定する発想＝**ネットワーク・スケールアップ法（NSUM）**の原点（Bernard ら） |
| 1989 | Freeman & Thompson が電話帳法で知人数を推定 |
| 1998 | Killworth ら、スケールアップ法の最尤推定量を導出。HIV 陽性者・レイプ被害者・ホームレス数の推定に応用 |
| 2001 | McCarty ら、総和法とスケールアップ法で **291**。「290」の誕生 |
| 2006 | Zheng, Salganik & Gelman（*JASA*）が同じ1,370人のデータを過分散モデルで再解析 → **中央値 約610・平均 約750**（90%の人が 250〜1,710） |
| 2010 | McCormick, Salganik & Zheng（*JASA*）が「潜在非ランダム混合モデル」で再々解析 → **平均 611・中央値 472**（対数正規分布によく合う） |

同じ生データから 290 → 750 → 611 と値が動いたのは、**よくある名前（Michael, James）の知人を人は思い出しきれない**ため。McCarty らは12個の名前全部で正規化したのに対し、Zheng らは珍しい名前（Jacqueline, Christina, Nicole）に合わせて正規化したから、値が2倍以上に膨らんだんだ。つまり「290」は思い出しバイアス込みの保守的な値、「600〜750」は補正後の値、という関係だよ。

そして Bernard–Killworth らの本当の遺産は数字そのものより、**NSUM が疫学・公衆衛生で「隠れた集団」を数える標準手法になった**こと。各国で「平均知人数 C」を測る研究が続いていて、米国の C ≈ 290 はその基準値として今も引用されてる。

## 4. 150・290・その先 ── 層として並べると矛盾しない

| 数 | 出どころ | 「知っている」の中身 |
| --- | --- | --- |
| 124.9 | Hill & Dunbar 2003（クリスマスカードで実際に接触） | 能動的に連絡している人 |
| 134 | Killworth ら 1984 | 頼みごとができる人 |
| **147.8 / 150 / 153.5** | Dunbar 1992 予測／カード調査の最大値 | 相手も、相手同士の関係も把握している安定した関係 |
| 231 / **290** | McCarty ら 2001 中央値／平均 | 互いに顔か名前で分かり、2年以内に接触 |
| 250〜500 | Killworth 1984・ダンバーの「メガバンド」層 | 顔見知り |
| 472〜750 | 2006・2010年の再解析 | 同上（思い出しバイアス補正後） |
| 約1,500 | ダンバーの最外層 | 顔に名前をつけられる人 |
| 〜5,000 | Pool & Kochen／Killworth ら 1990 | 生涯に知った人の総数 |

Hill & Dunbar 自身も「250〜5,000 は"知っている全員"で、その多くは親密なネットワークの一部ではない」と書いて、290 系の数字と 150 を**別の層**として棲み分けている。ダンバーの「約3倍ずつ」の階層（150→500→1,500）で見ると、290 は 150 と 500 の中間、ちょうど「ダンバー数の約2倍」の位置に落ちる。だから「150 vs 290、どっちが正しいか」ではなく、**定義の広さが違う二つのものさし**として理解するのが正解だと思う。

## 5. 数字そのもののいわれ（おまけ・検算済み）

- **290** = 2 × 5 × 29（楔数）。$290 = 17^2 + 1^2 = 13^2 + 11^2$ と、2通りに平方数の和で書ける。小惑星 290 Bruna、NGC 290 はきょしちょう座の星団、E.164 国番号 +290 はセントヘレナ。
- **291** = 3 × 97（半素数・ハッピー数）。国番号 +291 はエリトリア。
- **231** = 3 × 7 × 11 で、**21番目の三角数**（$21 \times 22 / 2$）。「知人数の中央値が三角数」は偶然だけど、ちょっときれい。
- **610** は**フィボナッチ数**（377, 610, 987）。2006年の中央値がこれなのも、もちろん偶然の一致。

# 創作への落とし込み案 （解説：37(サナ),Claude）

- 148(ダンバー)/150(ハクハン) と 290(ベルナード–キルワース)を「内側の輪・外側の輪」に見立てると、ナンバーテールズの関係図を同心円で描ける。
- 「同じ記憶を数え直したら 290 が 750 になった」── 思い出せない知人が実は2倍いる、という設定は物語の種になりそう。

# 補足

1992年原論文の本文は入手できず、式と数値は1993年の再掲論文から取得。「Dunbar's number」という呼称の初出（Christopher Allen 2004 説）と、Facebook 研究の具体的な平均値は今回裏取りは今回行っていない。
Gurevich 1961・Freeman & Thompson 1989 の具体的な推定値と、Killworth 本人が海洋学者だった点は原典未確認（後者は記憶ベース）。「中央値 231」は Wikipedia の記述で、2001年論文本文では確認できず。
なお、文章の要約と整理のため、Claudeでのセッション全文から一部を割愛しつつ、見出しや一部の生成文を編集している。
