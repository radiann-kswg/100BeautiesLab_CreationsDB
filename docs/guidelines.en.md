## 2. Permission for use (Primary Works)

In principle, **permission is required** for third parties to use images of works that are:

- Primary works, and
- Tagged with one of the following series tags (as written in `README.md`):
  - #運命線狐の記録
  - #フィジカル 9
  - #ナンバーテールズ
  - #運命線探偵 OCTOGINTA
  - #運命線探偵 78

  - #パストダイヴァー
  - #豹変系女子

For permission requests, please use the contact method described in `README.md`.

## 3. Tagging for secondary works

If you create secondary (derivative/fan) works based on characters from the primary works:

- Please either provide a link to the author’s homepage/account (as described in `README.md`), or
- Use the following secondary-work tags:
  - For the “NumberTales” series: `#ナンバーテールズの主人より`
  - For other series: `#運命線に届け`

(Using tags is optional, but appreciated.)

## 4. Prohibited acts (Secondary Works)

The following are prohibited as violations of the guidelines (as described in `README.md`):

1. Secondary works that excessively infringe on **R18G** (e.g. extreme gore/violence that causes physiological fear, or use in horror works).
2. Use in malicious applications, or expressions that seriously damage the impression of the work (e.g. false authorship, unauthorized commercial use, hate/offensive expressions that defame others).
3. Use in ways that seriously obstruct the author’s activities (e.g. attacks on servers, unauthorized reprints/resale of paid content, and uses that significantly involve copyright infringement through AI generation/learning).
4. Use of the work in ways that violate other creators’ guidelines.
5. Depictions that differ significantly from the official settings and may cause confusion.

For the official setting reference, see the link listed in `README.md`.

If you find a violation, please contact the author using the contact details listed in `README.md`.
